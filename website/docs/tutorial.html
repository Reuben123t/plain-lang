A short language tour

PLAIN combines readable statements with familiar expressions. Every block closes with end.

English and familiar expressions

set visitor to "Ada"
set points to 10
points += 5
say "Hello, " plus visitor
say "Points: " + points

Decisions and blocks

score = 85
if score is at least 80 then
    say "Passed"
otherwise
    say "Keep practicing"
end

Functions and loops

def greet(name):
    return "Hello, " plus name
end

for each name in ["Ada", "Grace"]
    say greet(name)
end
