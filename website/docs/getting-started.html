Getting started

Install PLAIN, run your first program, and learn the workflow in a few minutes.

Requirements and installation

Install Node.js 22 or newer, with npm, then obtain a source checkout of the repository.

npm ci
npm run build
node bin/plain.js --version
node bin/plain.js run examples/01_hello.plain

The last command runs the included hello-world example. You can use the checkout without a global install or downloaded executable.

Write and run a file

Create hello.plain in the repository directory:

set visitor to "Ada"
say "Hello, " plus visitor

Run it and check its syntax:

node bin/plain.js run hello.plain
node bin/plain.js check hello.plain
node bin/plain.js check hello.plain --json

Next steps
