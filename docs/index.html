// NATIVE WINDOWS GUI

          
PLAIN IDE (Native Python IDLE Desktop Equivalent)

          

            No Chrome. No browser. No localhost web servers. A pure compiled Windows Forms application (plain-ide.exe).
          

        

        
          ⬇ Download plain-ide.exe
        
      


      

        

          
📝 Editor Area Only on Open

          

            When files are opened via double-click, file association, or plain ide <file>, code loads directly into the editor. It never auto-runs on open.
          

        


        

          
⚡ F5 Run Module Execution

          

            Execute code strictly on demand by pressing F5 or clicking Run Module. Outputs stream live into the bottom IDLE interactive shell pane.
          

        


        

          
🎨 Custom Logo & No-BOM UTF-8

          

            Embedded multi-resolution custom emblem in title bar and taskbar. Automatic UTF-8 non-BOM file persistence ensures zero syntax parsing errors.

// ARCHITECTURE & CAPABILITIES

          
Technical Specifications

        

        
Version 1.2.0 Core

      


      

        
        

          

            
🛡️ Cybersecurity Recon

            Module: cyber
          

          

            Built-in offensive and defensive security suite. Perform multi-port TCP recon, audit HTTP headers, and scan CVE databases offline.
          

          
    
            
  • • cyber.port_scan(host, [ports])
    • 
            
  • • cyber.audit_security_headers(url)
    • 
            
  • • cyber.cve_lookup("CVE-2021-44228")
    • 
            
  • • cyber.detect_sql_injection(input)
    • 
          

        


        
        

          

            
🧠 Deep Learning & AI

            Module: ai
          

          

            Train neural networks directly in PLAIN without heavy third-party framework dependencies. Includes backpropagation and matrix ops.
          

          
    
            
  • • neural_network(layers, lr)
    • 
            
  • • train_ai(nn, data, targets, epochs)
    • 
            
  • • predict_ai(nn, input)
    • 
            
  • • linear_regression(x, y)
    • 
          

        


        
        

          

            
🌐 Live Network Web Servers

            Module: server
          

          

            Deploy production-grade HTTP/JSON endpoints bound to local and LAN ports. Accessible across WiFi and IP network interfaces.
          

          
    
            
  • • web_server(port, host: "0.0.0.0")
    • 
            
  • • route(server, "GET", path, handler)
    • 
            
  • • json_response({ ... })
    • 
            
  • • get_network_ips()
    • 
          

        


        
        

          

            
📐 Pythonic Syntax & Math

            Syntax Engine
          

          

            Natural symbols combined with straightforward keywords. Supports Set ABC = Main, math operations, and standard built-ins.
          

          
    
            
  • • Standard: =, +, -, *, /, **, //, %
    • 
            
  • • Variables: Set ABC = Main
    • 
            
  • • Converters: str(), int(), float(), bool(), type()
    • 
            
  • • Packages: import math / import cyber
    •
